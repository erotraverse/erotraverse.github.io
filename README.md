# EROTRAVERSE

Лендинг EROTRAVERSE — женского интимного фитнеса: офлайн-тренировки мышц тазового дна для женщин.

**Сайт:** https://erotraverse.github.io

## Что на странице

- Главный экран: название, для кого тренировки и оффер
- Описание тренировки: что это, кому подойдёт и что даёт
- Из чего состоит занятие
- Три кнопки записи ведут в Telegram-бота @erotraverse_request_bot: одно занятие, абонемент, онлайн по запросу
- Ссылка «Цены и частые вопросы» — тоже в бота
- Форма заявки «Имя + контакт + формат» — заявка сохраняется в базу Postgres на Railway и приходит владелице в Telegram

## Как устроено

Одна страница — файл `index.html`, без сборки. Сайт размещён на GitHub Pages: ветка `main` — основной сайт, ветка `test` — тестовая версия `/test/`.

Ссылки на Telegram задаются в одном месте — в объекте `TELEGRAM_LINKS` в конце `index.html`.
