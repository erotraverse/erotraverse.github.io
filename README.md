# EROTRAVERSE

Лендинг EROTRAVERSE — женского интимного фитнеса: офлайн-тренировки мышц тазового дна для женщин.

**Сайт:** https://erotraverse.github.io

## Что на странице

- Главный экран: название, для кого тренировки и оффер
- Описание тренировки: что это и кому подойдёт
- «Для жизни, а не для коврика»: чем EROTRAVERSE отличается и какая у него цель
- Что даёт тренировка
- Из чего состоит занятие
- С чего начать: путь новой ученицы, что взять с собой, противопоказания
- Частые вопросы
- Три карточки записи с ценами, кнопки ведут в Telegram-бота @erotraverse_request_bot: одно занятие, абонемент, онлайн по запросу
- Ссылка «Задать вопрос в Telegram» — тоже в бота
- Форма заявки «Имя + контакт + формат» — заявка сохраняется в базу Postgres на Railway и приходит владелице в Telegram

Цены записаны в двух местах: в карточках записи на сайте и в ответе «Сколько стоит?» в боте. Меняйте в обоих.

## Как устроено

Одна страница — файл `index.html`, без сборки. Сайт размещён на GitHub Pages: ветка `main` — основной сайт, ветка `test` — тестовая версия `/test/`.

Ссылки на Telegram задаются в одном месте — в объекте `TELEGRAM_LINKS` в конце `index.html`.
